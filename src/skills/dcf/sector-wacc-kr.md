# 섹터별 WACC 조정 — 한국 (KOSPI / KOSDAQ)

이 표는 **합리성 밴드(sanity band)**다 — SKILL.md Step 3의 bottom-up CAPM(WACC = (E/V)·Ke + (D/V)·Kd·(1−t),
Ke = Rf + β×ERP, Rf는 실시간 10년 국고채)으로 WACC를 직접 계산한 뒤, 그 결과가 아래 레인지 안에 드는지 확인하는
용도로 쓰라. 레인지에서 값을 바로 집어 쓰지 마라(그러면 베타·실시간 금리를 버리게 된다). 레인지 자체는 ~3%
무위험금리·4.87% base ERP를 가정하므로, 미국 무위험금리를 위에 다시 얹지 마라.

> **ERP 이중계상 금지:** base ERP(4.87%, Damodaran 한국 2026.1 핀값)는 시장 전체 프리미엄만 담는다. 아래 **리스크 플래그**(지배구조·코리아 디스카운트·순환출자·지주사 등)는 *그 종목 고유의* 추가 위험을 다루는 별도 채널(서술+민감도)이지 base ERP를 끌어올리는 근거가 아니다. 같은 위험을 ERP 상향과 플래그 양쪽에 넣지 마라.

## 섹터 판별

`get_financials_kr`는 표준화된 `sector` 필드를 반환하지 않는다. 회사의 주력 사업(사업 영역,
KRX 업종분류)으로 섹터를 추론해 아래 표에 매칭하라.

## 리스크 플래그 — WACC에 임의 가산하지 마라

아래 요인들은 실재하는 위험/완화 요인이지만, 특정 ±% 크기를 붙일 **출처 있는 실측치가 없다** — 임의 프리미엄을 CAPM WACC에 가산하는 순간 WACC 전체가 검증·재현 불가능해진다(같은 질문에 다른 답). 대신 세 채널로 반영하라:

1. **플래그는 근거와 함께 서술** — 해당 여부를 도구 데이터로 판정해 결과에 명시한다: 고부채는 `ratios.debtToEquityPct`, 소형주는 `valuation.marketCap`, 계열·순환출자·특수관계는 `get_large_holders_kr`/`read_filings_kr`(governance), 밸류업 실행은 `get_filings_kr`. 근거 없는 플래그는 달지 않는다.
2. **수치 영향은 Step 6 민감도 그리드가 담당** — 가산 플래그가 1개 이상이면 "리스크 플래그 반영 시나리오 = WACC +1% 열"임을 명시하고 평가 코멘트를 그 열 기준으로도 병기한다. 완화 플래그가 우세하면 −1% 열이 그 시나리오다. base WACC 자체는 CAPM 계산값 그대로 둔다.
3. **수치 가산은 사용자 오버라이드로만** — 사용자가 쿼리나 `.dexter`로 프리미엄(예: size premium 실증 연구값)을 지정한 경우에만 가산하고, 출처를 "user override"로 가정표에 표기한다.

**가산(리스크) 플래그 체크리스트:**
- 고부채 (D/E > 1.5)
- 소형주 (시총 < 1조원)
- 지배구조 / 코리아 디스카운트 (재벌 계열, 불투명한 특수관계자 거래)
- 순환출자 노출
- 지주사 구조 — 애초에 `kr-sotp-holdco`로 라우팅할 대상인지 먼저 확인
- 특정 고객 / 단일 매수자 의존

**완화 플래그 체크리스트:**
- 해자를 갖춘 시장 리더 / 반복·구독 매출 모델
- 투자등급 신용등급 (KR 기준 AA- 이상)
- 변동성 낮은 꾸준한 배당주
- 밸류업(기업가치제고) 적극 실행 (계획 공시 + 자사주 소각/배당확대 실행 확인)

## 합리성 점검

- 가치 창출 기업은 보통 WACC가 ROIC보다 2~4% 낮아야 한다.
- WACC > ROIC이면 가치를 훼손하고 있을 수 있다.
- 가능하면 KOSPI 동종 업계와 교차 확인하라.
- 부채비용은 **~22% 법인세율**(K-IFRS 실효; 미국 30% 아님) 기준 세후로 적용한다.
