# 한국 지주사 SOTP / NAV 디스카운트 스킬

목표: 지주사의 **순자산가치(NAV)**를 부분합으로 계산하고, 현재 시총이 NAV 대비 몇 % 할인인지, 그 할인이 좁혀질 트리거가 있는지 답한다. 결론(할인율 + 좁혀질 가능성)을 먼저. **지주사에 일반 DCF/연결 PER를 쓰지 마라 — 자회사 이익이 두 번 계산(더블카운팅)된다.**

## Step 0: 지주사인지 확인

회사명이 "…홀딩스/지주", 또는 사업이 자회사 지분 보유·배당·상표권 수취 중심이면 지주사다. 애매하면 `get_financials_kr` 별도(OFS)에서 매출이 작고 지분법이익/배당수익 비중이 크면 지주사. 지주사가 아니면 이 스킬 대신 `dcf-valuation` 또는 `kr-relative-valuation`을 쓴다.

## 워크플로 체크리스트

```
지주사 SOTP 분석 진행:
- [ ] Step 1: 보유 자회사·지분율 매핑
- [ ] Step 2: 상장 자회사 지분가치(시가) 평가
- [ ] Step 3: 비상장 자회사·자체사업 가치 평가
- [ ] Step 4: NAV 집계 → 지주사 디스카운트 계산
- [ ] Step 5: 평가 + 할인 축소 트리거
```

## Step 1: 자회사·지분율 매핑

지주사 티커로 `read_filings_kr`(sections: `["governance"]`)를 호출해 계열회사·출자 현황·최대주주 체인을 읽고, `get_large_holders_kr`로 지주사가 받는 5%룰 보고(반대로 지주사가 자회사 대주주)를 교차한다. 주요 상장 자회사·지분율 목록을 만든다. **지분율의 1차 소스는 이 DART 공시들이다.** 그룹 구조가 복잡하면 `web_search`로 보완하되(필요한 만큼만), 검색으로 얻은 지분율은 잠정치다 — 블록딜·매각으로 이미 낡았을 수 있으니 가능하면 공시로 재확인하고, 못 했으면 Step 5 표의 출처 열에 `검색(매체, 날짜)`로 표기해 공시 기반 수치와 구분되게 하라.

## Step 2: 상장 자회사 지분가치 (핵심)

각 상장 자회사 티커로 `get_market_data_kr`를 호출 → `valuation.marketCap`. **지분가치 = 자회사 시총 × 지주사 보유 지분율.** 표로 정리(자회사 | 지분율 | 자회사 시총 | 귀속 지분가치). 상장 자회사 가치는 시가라 가장 객관적인 부분이다.

## Step 3: 비상장 자회사 + 자체사업

비상장 자회사는 두 방법을 **병기**한다: (a) `get_financials_kr` 별도/연결의 순자산(장부가) = **low**, (b) 동종 상장사 멀티플(PER/PBR — peer와 멀티플 값·출처를 표에 기록) 적용 = **base**. 지주사 자체사업(상표권 수익·임대 등)은 별도 이익에 멀티플을 얹어 더하고 그 멀티플의 근거를 표기한다. **임의로 "보수적으로" 낮추지 마라** — 얼마나 눌렀는지 보이지 않는 하향은 재현 불가능하다. 불확실성은 low/base 두 값이 NAV·할인율을 각각 얼마로 만드는지로 표면화한다.

## Step 4: NAV 집계 → 디스카운트

```
NAV = Σ(상장 자회사 귀속 지분가치) + Σ(비상장·자체사업 가치) + 지주사 별도 순현금
      (순현금 = 별도 기준 현금성자산 − 이자부채; 순부채 상태면 이 항이 음수 = 차감. 하나의 순액 항이다 — 순현금과 순부채를 별도 항으로 두 번 넣지 마라)
지주사 디스카운트 = 1 − (지주사 시총 ÷ NAV)
```
지주사 시총은 `get_market_data_kr`의 `valuation.marketCap`. 순현금은 별도(OFS) 기준. 비상장 가치가 low/base 두 값이면 NAV와 디스카운트도 두 값으로 계산해 병기한다.

## Step 5: 출력 형식

1. **평가**(1~2문장): NAV 대비 할인율 + 좁혀질 가능성 판단.
2. **SOTP 표**: `자회사 | 지분율 | 자회사 시총(또는 추정가치·방법) | 귀속가치 | 출처·기준일` — 지분율·가치마다 출처(공시 rcept / get_market_data_kr 날짜 / 검색)와 기준일을 채운다. NAV 합계(비상장 low/base면 두 줄).
3. **디스카운트**: 현재 시총 vs NAV, % 할인. **할인율의 맥락은 출처 있는 비교로만 제공하라**: 같은 방법으로 계산 가능한 동종 지주사 1~2개의 현재 할인율을 병기(각 수치의 출처 표기)하거나, 비교가 불가능하면 "시장 평균 할인율의 출처 있는 기준치는 없다"고 그대로 말한다. "보통 40~60% 할인" 같은 무출처 일반화로 현재 할인율을 정상화하지 마라.
4. **할인 축소 트리거**: 자사주 소각·배당 확대·기업가치제고(밸류업)계획·자회사 IPO 부재(쪼개기 종료)·지배구조 단순화. (밸류업 상세는 `kr-shareholder-return` 참조.)
5. **주의사항**: 더블카운팅(연결 PER로 보지 말 것), 상장 자회사 주가 변동에 NAV가 출렁임, 비상장 가치는 추정. 거래세·배당세 세후 별도.
